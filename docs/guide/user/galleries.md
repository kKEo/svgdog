# Galleries

Each gallery shows finished diagrams with the spec that draws them. Find the one closest to what you want to draw, copy its spec, and change the names.

| Gallery | What it shows |
| --- | --- |
| [Theme gallery](theme-gallery.md) | One diagram in every built-in theme, light and dark |
| [Flow gallery](flow-gallery.md) | How parts connect: left to right and top to bottom |
| [Layers gallery](layers-gallery.md) | Tiers and zones stacked as bands |
| [Sequence gallery](sequence-gallery.md) | Messages between participants, in time order |
| [State gallery](state-gallery.md) | The states of one thing and what moves it between them |
| [Timeline gallery](timeline-gallery.md) | Plans and histories along a line |
| [Compare gallery](compare-gallery.md) | Before and after, option A and option B |
| [Free gallery](free-gallery.md) | Drawings where you place every box yourself |

To choose a type first, see [Diagram types](diagram-types.md#which-one-should-i-pick).

The pictures are drawn by SVGDog from the specs shown, every time the guide is built, so what you see is what the spec gives you.
